# Messor barbarus · hormiga obrera (sprites top-down)

Hormiga obrera *Messor barbarus* en vista cenital ortográfica, estilo casual, con animaciones **quieta**, **caminar** y **atacar**. Dibujada y animada por código (rig vectorial con IK 3D).

**Demo en vivo:** https://kgonzalezz.github.io/messor-barbarus-sprites/

La página incluye el visor de animaciones, una demo jugable y la exportación de sprite sheets PNG (128–1024 px) con su JSON de metadatos.
